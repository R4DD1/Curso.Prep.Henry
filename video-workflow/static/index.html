Cómo usar Video Workflow

1. Pegá tu API key de Siray arriba y guardala.

2. Subí la imagen de tu avatar.

3. Escribí un prompt describiendo el movimiento.

4. Elegí el motor (Wan 3.0 recomendado) y la duración.

5. Activá el escalado a 1080p si querés calidad final.

6. Hacé click en Crear video.
